Presto2k 0.3.0: membership and decisions from LiPDverse export 2026-11-17b, presto-recipes
branch presto2k-pages2k.
Same criteria and reviews as 0.2.0, except that two rules about annual information content are
now method screens rather than compilation rules (Nick McKay, 2026-11-18): records whose
successive values repeat at least half the time, and records in units of rates per century or
millennium. The compilation holds records far coarser than annual, and the repeat rule had also
excluded coarse sediment records whose values repeat between samples. The presto-LMR and
presto-BayGMST screens (Presto2k_0_2_0_lmr, Presto2k_0_2_0_localfdr10) now apply both rules and
select exactly the same 715 and 228 records as from 0.2.0, so the 0.2.0 reconstruction runs stand.
1206 records in 0.2.0, 1218 in 0.3.0 (1093 datasets); changes_from_0_2_0.csv lists the 15 records
added and 3 removed (three datasets now keep another column of the same measurements).
Frozen; later versions get their own folder.
